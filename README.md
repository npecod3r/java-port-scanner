# Java Port Scanner

Многопоточный сканер портов на Java для быстрой проверки открытых портов на заданном узле.

## Запуск

1. Клонируйте репозиторий:
  bash
git clone [https://github.com/npecod3r/java-port-scanner.git](https://github.com/npecod3r/java-port-scanner.git)
cd java-port-scanner

2. Скомпилируйте и запустите проект через терминал:
  bash
javac *.java
java Main

Либо откройте файлы в IntelliJ IDEA и запустите класс `Main`.
